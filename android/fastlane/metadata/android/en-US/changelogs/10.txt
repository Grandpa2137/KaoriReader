0.2.0

- every JSON store now writes atomically (tmp + rename, previous version kept as .bak);
  a corrupt progress file is moved aside instead of being overwritten
- removed the RECORD_AUDIO permission: voice input goes through the system recognizer,
  which does its own recording
- "thinking: disabled" is sent only to DeepSeek, so stricter OpenAI-compatible endpoints
  do not reject the request
- page fetching is capped at 2 MB of text
- if the Android Keystore refuses to encrypt the API key, the app says so instead of
  silently saving nothing
- GitHub Actions runs the unit tests on every push
